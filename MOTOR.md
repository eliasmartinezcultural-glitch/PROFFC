# YO FUTBOLISTA — SIN 9 FC

Sistema móvil-first para vivir el equipo desde adentro.

## Arquitectura 3.0
- data.js: fuente única de verdad
- engine.js: relaciones, consultas y validación
- app.js: presentación y navegación
- styles.css: sistema visual responsive
- index.html: shell estático GitHub Pages

## Principio
Muchísima estructura interna; mínima carga cognitiva para el jugador.

## Integridad
No se inventan jugadores, estadísticas, resultados, dorsales, formaciones ni estados. Lo no informado se conserva como no informado.
